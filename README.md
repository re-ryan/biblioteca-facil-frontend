# Biblioteca Fácil

Frontend em React para consulta e administração do catálogo do Biblioteca Fácil. A plataforma reúne livros cadastrados por bibliotecas parceiras e facilita a descoberta de exemplares pelos leitores.

## Tecnologias

- React
- Vite
- React Router
- Material UI
- Vitest e React Testing Library

## Requisitos

- Node.js 24 ou superior
- npm 11 ou superior

## Execução

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

A aplicação ficará disponível em `http://localhost:5173`.

## Verificações

```bash
npm run lint
npm run test
npm run build
```

Nesta primeira feature, o CRUD utiliza dados locais mantidos durante o uso da página. A integração com APIs será adicionada na feature correspondente.
